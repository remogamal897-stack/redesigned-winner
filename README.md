# رفيقة الدراسة

موقع دراسة قابل للنشر العام، ويدعم واجهة الويب وتوليد الملخصات والأسئلة عبر مزوّد ذكاء اصطناعي يختاره مالك الموقع. لا يطلب من الزوار إدخال مفاتيح API؛ مفاتيح المزوّد تحفظ كأسرار في إعدادات الاستضافة.

## تشغيله

يتطلب Node.js 20 أو أحدث.

1. انسخي `.env.example` إلى متغيرات البيئة في الاستضافة.
2. أضيفي المفاتيح التي تريدين توفيرها للطالبات كأسرار في إعدادات الاستضافة: `GEMINI_API_KEY` و/أو `OPENAI_API_KEY` و/أو `DEEPSEEK_API_KEY`. تظهر للطالبات الخدمات التي أعددتِ مفاتيحها فقط.
3. شغّلي `npm start`، والمنفذ يقرأ من `PORT`.
4. اربطي نطاقك بمنصة الاستضافة لتوفير رابط عام.

متغيرات اختيارية:
- `AI_PROVIDER=gemini` (أو `openai` أو `deepseek`) لاختيار الافتراضي.
- `SITE_NAME=رفيقة الدراسة` اسم ثابت يديره مالك الموقع من إعدادات الاستضافة؛ لا يستطيع الزوار تغييره.
- `OPENAI_API_KEY`
- `DEEPSEEK_API_KEY`
- `TRUST_PROXY=1` فقط إذا كانت منصة الاستضافة تضبط `X-Forwarded-For` بنفسها.

الموقع يحد طلبات كل عنوان شبكة إلى 25 طلباً خلال 10 دقائق، ويضع حدّاً لحجم الطلب. يمكن تعديل هذه القيم في `server.js`. الاستهلاك المالي لواجهة API يقع على حساب المالك، لذا ينبغي ضبط سقف ميزانية وتنبيهات في لوحة مزود الخدمة.

## البيانات والخصوصية

النسخة الحالية تحفظ المحاضرات والروابط في متصفح كل مستخدم فقط؛ لا يوجد تسجيل دخول أو تخزين سحابي أو مزامنة بين الأجهزة. ملفات PDF وDOCX تستخرج نصوصها محلياً في المتصفح. عند طلب تلخيص أو أسئلة، يرسل نص المحاضرة إلى مزوّد الذكاء الاصطناعي المختار.
